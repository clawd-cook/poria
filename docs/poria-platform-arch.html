Poria AINative 交付平台

能力即包、自举安装、独立可测。从表单到 MR 合并的静默端到端流水线，可观测、可重现，仅在无法自主解决时通过京ME与人交互。

架构设计 v2 2026-09-16

设计原则

能力即包
每个 channel、resource、command、skill 独立发包，独立测试，独立安装。
自举安装
Poria 通过 init 逻辑装载自身产出的能力 + 第三方能力。Eat your own dog food.
Apps 是壳
Next.js 和 Tauri 只做信息输入/输出，内部通过能力调用完成业务。
独立可测
每个包导出 In-Memory 替身，上层包零外部依赖即可完整测试。

Pipeline 状态机

住在 core/pipeline/，被 commands/pipeline 引用。不是独立 domain 层。

Pipeline 级

stateDiagram-v2
    [*] --> CREATED
    CREATED --> RUNNING : submit
    RUNNING --> COMPLETED : all stages done
    RUNNING --> BLOCKED : stage needs human
    BLOCKED --> RUNNING : human reply
    RUNNING --> FAILED : unrecoverable
    FAILED --> CANCELLED : cancel
    RUNNING --> CANCELLED : cancel

Stage 级

stateDiagram-v2
    [*] --> PENDING
    PENDING --> RUNNING : advance
    RUNNING --> COMPLETED : success
    RUNNING --> FAILED : error
    FAILED --> RUNNING : retry ≤3×
    FAILED --> BLOCKED : retries exhausted
    BLOCKED --> RUNNING : human reply
    COMPLETED --> [*]

京ME 人工回路

人工回路是一个 Skill（skill:human-loop），依赖 channel:jme，和其他 AI 能力同级。

异常分类 → 路由

IssueClass策略通知
compilation_error重试 ×3 → 通知开发者
test_failure重试 ×3 → 通知开发者
requirement_ambiguous立即通知产品
merge_conflict立即通知开发者
permission_denied立即通知运维
infra_failure立即通知运维
超时升级：T+0 初始通知 → T+30m 重发@提醒 → T+2h 升级上级 → T+8h 标记手动处理

Apps 层

apps/web Next.js 全栈
Server Actions 直接调用 packages 的 Command/Skill，不经 HTTP 中转。SSE 推送事件。App Router + Kanban Dashboard + 需求表单。
apps/desktop Tauri
Sidecar 运行 Node.js，调用同一套 packages 能力。前端组件从 web 共享。覆盖本机 Agent 场景。
关键决策：Next.js Server Actions 就是 API 层。Tauri 通过 Node sidecar 共享能力。两个 App 零业务逻辑，纯壳。

测试策略

每个包导出自己的 In-Memory 测试替身，上层包零外部依赖即可完整测试。

层方式隔离验证点
core/*纯单元零依赖状态机全路径、契约类型
infrastructure/*单元 + 集成Mock FS/网络PluginLoader 拓扑排序、EventStore 持久化
channels/*单元 + 集成Mock HTTP每个 channel 导出 InMemory 替身
resources/*单元 + 集成Mock 进程Agent 调度、worktree 生命周期
commands/*Use CaseIn-Memory 能力Pipeline 端到端编排
skills/*Use CaseIn-Memory channelPRD 解析、TRD 生成、人工回路
apps/*E2E完整组装Playwright / WebDriver

关键决策

#决策选择理由
D1包组织按能力类型分组独立发包、测试、安装
D2能力加载自举 PluginLoader + manifest自己装自己 + 装第三方
D3Apps 架构Next.js + TauriWeb 覆盖远程，Tauri 覆盖本机
D4PipelineCommand 编排 Skills不是独立 domain，是能力组合
D5API 层Server Actions 直调 packagesNext.js 就是 API，不中转
D6人工回路Skill 包 (依赖 jme channel)统一契约，和其他能力同级
D7测试隔离每包导出 In-Memory 替身上层零外部依赖，完整覆盖
