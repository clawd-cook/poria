
## 规约

- **禁止静默收敛（TRD 跨章冲突必签收，不许暗决策）**：TRD 各章出现冲突时，agent **禁止**按某一方静默收敛（**尤禁只写代码注释了事**）。冲突含——状态数/行为跨章不一致、PRD 批注（如 R1）与正文矛盾、接口字段无法支撑某声明状态、声明了却不可达的态。处置：必须在 §11 落**未决项**、走定稿签收，由用户裁决；不得在正文或代码注释里私自按一方拍板。触发源由 `exit-rules.md`「组件规格投影单视角自洽核对 + 禁止静默收敛」检查逼出喂进 §11（reviewer 逐份读组件规格投影发现的矛盾即由此进签收），不改 §11 签收流程本身。
- **合成组件（无单一容器）须暴露签收，禁止自选 root**：组件的成员散落为大容器（页面帧/大骨架）的直接兄弟、无任何单一节点框住它们（header/banner/散落 badge）时，是**设计稿数据质量缺陷**——本应合并进一个 frame。agent **禁止**随手挑一个成员当 rootNodeId 糊弄（下游 `get_node_data` 会漏捞其余成员，属静默收敛）。处置：analysis 检出即上报主 agent → 向用户暴露 → 签收两路（改稿合并 / 占位自建 wrapper 降级）。判定见 `relay-component-analysis.md`「合成组件」，编排见 `schema.yaml`「合成组件处置」，闭环见 `exit-rules.md`。
