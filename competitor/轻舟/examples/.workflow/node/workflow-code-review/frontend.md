# code-review 阶段 frontend 项目协议

仅当项目为 FRONTEND 项目时，遵循本协议。

## UI审计

**仅当**本次需求涉及UI时才做；否则跳过本节。

审计UI的**布局（页面布局、组件间布局等）、样式&样式比例、层级（层级是否合理？是否重叠？）、动画、CDN占位等(不限于此)**UI是否合理还原，当前渲染模式下是否支持这么实现。

**使用subagent进行审计**不阻塞当前审计，拆分两个subagent，一个单独做布局&层级审计，另一个做样式、比例、动画、CDN占位等UI(不限于此)审计。

## 交互审计

**仅当**本次需求涉及UI时才做；否则跳过本节。

1.审计交互是否在逻辑层已实现。2.审计是否存在使用三方API导致的坑。3.审计交互是否已实现需求
**当前渲染模式是否支持**————如人机交互（上下滚动、点击、双击、长按等等各种可能的人机交互）是否支持。

**使用subagent进行交互审计**不阻塞当前审计，用subagent单独做交互审计
